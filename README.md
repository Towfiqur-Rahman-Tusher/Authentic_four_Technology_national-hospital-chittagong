# National Hospital Chattogram - Flutter UI

UI-only Flutter demo with local hospital logo and doctor images.

## Run
1. Extract the ZIP.
2. Open the `national_hospital_ui` folder in Android Studio.
3. Run:
   ```bash
   flutter pub get
   flutter run
   ```

## Local images
Image files are in `assets/images/`. The asset folder is registered in `pubspec.yaml`.
Doctor image paths are mapped in `lib/main.dart` using the provided filenames.

Note: doctor fees, specialties, qualifications and visiting hours are demo text and should be verified with the hospital before real use. No backend or real appointment booking is connected.
